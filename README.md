# Exploración de datos de pingüinos de Palmer con R

## Descripción del proyecto

Este repositorio contiene un análisis exploratorio de datos morfométricos de pingüinos del archipiélago Palmer, en la Antártid, como parte de las actividades del curso **Optimización de la gestión de ecosistemas marinos y recursos pesqueros en Latinoamérica mediante ciencia abierta (Edición 2026)**.

## Objetivos

- Importar y explorar un conjunto de datos abiertos utilizando R.
- Visualizar características morfométricas de diferentes especies de pingüinos.
- Aprender a definir y utilizar funciones sencillas.
- Practicar el control de versiones mediante GitHub.

## Conjunto de datos

Se utiliza el conjunto de datos *Palmer Penguins*, que incluye información sobre tres especies de pingüinos: Adelia, barbijo y papúa.

**Fuente:** [Conjunto de datos en Zenodo](https://zenodo.org/records/12772944)

Las herramientas (R 4.5.1) fueron usadas a través de JupyterHub, proporcionado por la propia iniciativa.
